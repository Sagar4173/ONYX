# Historical Design and Plan Records

The files under `docs/superpowers/plans/` and `docs/superpowers/specs/` are
dated snapshots created during implementation. They are retained for design
history and are not current operating documentation.

- The date in each filename identifies the snapshot.
- Descriptions of incomplete work, test counts, endpoints, deployment steps, or
  architecture may be outdated.
- Current behavior is defined by the code and the living documents in
  `docs/`, especially `API.md`, `ARCHITECTURE.md`, `DEPLOYMENT.md`,
  `INSTALLATION.md`, `PROJECT_STATUS.md`, and `SECURITY.md`.
- Do not rewrite a historical plan to match later implementation. Add a new
  dated document when a decision is superseded.

Internal execution ledgers under `.superpowers/` are not part of the tracked
documentation set and must not be staged in commits.
